# Shared Project Structure

Single source of truth for this project's folder layout, naming, and architecture. Skills link
here instead of duplicating it. Verify against the live tree before relying on a detail.

## Stack

Laravel 13 + Inertia v3 + React 19 (React Compiler enabled) + TypeScript (strict) + Tailwind
CSS 4 + Radix-style composition + Motion React. Tests: Jest + React Testing Library for React,
Pest for PHP/browser. Build: Vite. Routes typed via Wayfinder.

## Path Alias

- `@/*` -> `resources/js/*` (see `tsconfig.json`). Prefer `@/...` imports over deep relative paths.

## Frontend (`resources/js/`)

```text
resources/js/
├── app.tsx                  # Inertia client entry (Vite input)
├── setupTests.ts            # Jest setup
├── components/              # Reusable UI components — PascalCase *.tsx (e.g. Button.tsx)
│   └── sections/            # Page section components — *Section.tsx + Section.tsx wrapper
├── hooks/                   # Reusable hooks — camelCase useX.ts (e.g. useToggleState.ts)
├── lib/                     # Framework-agnostic utilities + co-located *.test.ts (utils.ts, photos.ts)
├── pages/                   # Inertia page components — lowercase (welcome.tsx, styleguide.tsx)
├── providers/              # React context providers (AppProvider.tsx, ColorModeProvider.tsx)
│   ├── context/             # Context objects — *Context.ts
│   └── hooks/               # Provider-internal hooks (useNotificationState.ts)
├── types/                   # Shared TS types (index.ts, auth.ts, global.d.ts, vite-env.d.ts)
├── __mocks__/               # Jest mocks (fileMock.ts)
├── actions/                 # GENERATED by Wayfinder — do not hand-edit
├── routes/                  # GENERATED by Wayfinder — do not hand-edit
└── wayfinder/               # GENERATED by Wayfinder — do not hand-edit
```

- Styles entry: `resources/css/app.css` (Tailwind 4).

### Placement Rules

| What you are creating                                   | Where it goes                          |
| ------------------------------------------------------- | -------------------------------------- |
| Reusable UI component                                   | `resources/js/components/`             |
| Page section (composed block of a page)                 | `resources/js/components/sections/`    |
| Inertia page (server-rendered route target)            | `resources/js/pages/`                  |
| Reusable hook                                           | `resources/js/hooks/`                  |
| Pure utility / framework-agnostic logic                 | `resources/js/lib/` (+ co-located test)|
| Context provider                                        | `resources/js/providers/`              |
| Context object for a provider                           | `resources/js/providers/context/`      |
| Hook used only by one provider                          | `resources/js/providers/hooks/`        |
| Shared TypeScript type                                  | `resources/js/types/`                  |

- Do not create new base directories under `resources/js/` without user approval.
- Never hand-edit `actions/`, `routes/`, `wayfinder/`; import generated route helpers from them.

## Backend (`app/`)

```text
app/
├── Http/Controllers/        # Inertia::render(...) endpoints
├── Http/Middleware/
├── Models/
└── Providers/
```

- Routes in `routes/`, migrations/factories/seeders in `database/`, config in `config/`, tests in `tests/`.

## Tooling Notes

- React Compiler is enabled (`babel-plugin-react-compiler`): manual `memo`/`useMemo`/`useCallback`
  are usually unnecessary; add them only with a measured reason.
- Vite plugins: Laravel, Inertia, React (compiler), Tailwind, Wayfinder (`formVariants`).
- Verification: `npm run types:check`, `npm run lint:check`, `npm run build`, `npm test`;
  PHP via Pest + `vendor/bin/pint --dirty --format agent`.
